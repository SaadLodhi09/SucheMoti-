## Key Architectural Decisions
1. **Frontend-Only University Project Architecture:**
   - Single-Page Application feel with zero build tools or bundlers.
   - Clean, modular separation:
     * Semantic HTML5 markup across all pages.
     * Design tokens, modern flexbox/grid, keyframes emulating Framer Motion spring physics.
     * Vanilla ES6 modules: state management via localStorage, event delegation, custom events.
   - High educational value: Every line of JavaScript and CSS can be articulated and defended in a university web engineering viva without external framework magic.

2. **Luxury Aesthetic Strategy:**
   - Avoiding generic template vibe (no Bootstrap cards, no stock purple gradients).
   - Warm obsidian darks, iridescent oyster creams, muted brushed gold accents.
   - Cormorant Garamond serif headings paired with Plus Jakarta Sans UI typography.
   - High-performance spring curves (`cubic-bezier(0.16, 1, 0.3, 1)`).
